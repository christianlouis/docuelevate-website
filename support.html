Support

For help with sign-in, document processing, provider connections or privacy requests, email docuelevate@christian-louis.de.

When reporting a problem, include the affected integration and a timestamp. Never send passwords, API keys or OAuth client secrets.

For account deletion in the web or iOS application, including support for older versions, use the account-deletion instructions.

Create and configure an account

Open registration on a server that permits public signup. Confirm the current terms and privacy policy, then verify your email before signing in. The setup journey guides you through your profile, a personal or shared space and optional storage connections. You can begin without connecting a cloud provider.

Self-hosted operators control registration availability and email delivery. Provider sign-in options depend on the server configuration.
